TacticPod command menu (115200 baud; finish each command with Enter):
  IMU ON       - print IMU readings at 10 Hz
  IMU OFF      - stop printing; sampling continues (100 Hz when recording)
  RECORD STATUS / READ - legacy read-only compatibility; use TCB for new sessions
  RECORD READ  - export committed recordings as CSV while stopped
  DIAG         - display JEDEC and SFDP information once (while idle)
  DIAG ID      - read-only raw flash identity/SFDP evidence (OBS/COMP stopped)
  GPS ON / GPS OFF / GPS STATUS - GPS output (OFF at boot); UART always receives
  GPS RAW      - capture 10 seconds of UART bytes without configuring GPS
  GPS SCAN     - stopped-only, receive-only six-baud scan; restores 38400
  GPS RATE     - measure separate GGA/RMC cadence for 15 seconds, no fix needed
  GPS CONFIG   - stopped-only, read current receiver settings using UBX polls
  GPS 10HZ TEST - stopped-only, snapshot then verified RAM-only GPS+Galileo test
  GPS RESTORE  - stopped-only, restore and verify the saved GPS RAM snapshot
  OBS START / STOP / CLEAR / STATUS - bounded RAM observations; no flash writes
  COMP START / STOP / CLEAR / STATUS - opt-in RAM compression; no flash writes
  TCB START / STOP / STATUS / READ - bounded append-only compact sessions
  TCB DURATION seconds|UNLIMITED - stopped only, 1..1800 or until stop; default 120; drain deadline 60 seconds
  BUTTON D0: hold 3s to start; tap, release, then hold 3s within 5s to stop
  FIELD EVENTS - drain bounded timestamped RAM events while stopped; overwritten count explicit
  Button starts record until stopped. Idle off-USB: System ON standby (GPS UART/IMU/flash/LED off); USB keeps it awake
  BAT STATUS - nominal voltage, trust, warnings, ADC faults; no battery presence inference
  BAT CAL measured_mV / BAT MODE USB|CELL - stopped-only RAM calibration/arming
  BAT LIMITS warn stop hard recover - stopped-only millivolt thresholds
  UART LOOPBACK TEST - explicit D6-to-D7 test; disconnect GPS UART first
